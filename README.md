# Mohammad Almasri — Portfolio

Personal portfolio site: services, selected work and experience, with a command palette (press <kbd>Ctrl</kbd> <kbd>K</kbd>) to jump anywhere.

Built with Next.js, React, Tailwind CSS and Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All text, services, projects and experience live in [`src/data/site.ts`](src/data/site.ts). Project images sit next to it in `src/data/`.
